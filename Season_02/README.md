# فصل دوم

در این فصل، مهارت‌های پایه برای ایجاد، ویرایش، آزمایش و اعتبارسنجی فایل‌های HTML و CSS آموزش داده می‌شود. هدف، اطمینان از صحت عملکرد و نبود خطا در کدها پیش از ورود به جزئیات پیشرفته‌تر است.

نحو HTML به مجموعه قوانینی گفته می‌شود که هنگام کدنویسی عناصر HTML باید رعایت شوند. رعایت این قواعد، ساختار استاندارد و قابل‌پردازش سند را تضمین می‌کند.

هر سند HTML از دو بخش اصلی تشکیل شده است:  
-----اعلان DOCTYPE  
-----درخت سند (Document Tree)  

در HTML5، اعلان DOCTYPE به‌صورت ساده شده و در ابتدای سند نوشته می‌شود. این اعلان اولین خط کد است و به مرورگر اطلاع می‌دهد که سند بر اساس HTML5 ایجاد شده است.

درخت سند پس از DOCTYPE آغاز می‌شود و شامل عناصر HTML است که محتوا و ساختار صفحه وب را تعریف می‌کنند.

اولین عنصر در درخت سند، عنصر html است که به‌عنوان عنصر ریشه شناخته می‌شود و سایر عناصر را در بر می‌گیرد.
درون عنصر html باید دو عنصر اصلی قرار بگیرد:  
-----عنصر head: شامل اطلاعات توصیفی و فراداده‌های صفحه است.  
-----عنصر body: شامل ساختار و محتوای اصلی صفحه وب است.  

از آنجا که این ساختار در تمامی اسناد HTML تکرار می‌شود، استفاده از یک الگو (Template) یا سند مشابه، رویه‌ای مناسب برای شروع کدنویسی است.

در HTML5، نام عناصر را می‌توان با حروف کوچک، بزرگ یا ترکیبی از آن‌ها نوشت؛ اما برای حفظ یکدستی، استفاده از حروف کوچک توصیه می‌شود.

تنها استثنا، اعلان DOCTYPE است که به‌صورت تاریخی معمولاً با حروف بزرگ نوشته می‌شود، هرچند نوشتن آن با حروف کوچک نیز از نظر فنی معتبر است.

بیشتر عناصر HTML با یک برچسب آغازین شروع می‌شوند و با یک برچسب پایانی پایان می‌یابند. برچسب پایانی مشابه برچسب آغازین است، با این تفاوت که دارای اسلش پیش از نام عنصر است؛ مانند </ h1>.(&lt;/h1&gt;)

محتوای عنصر میان برچسب آغازین و پایانی قرار می‌گیرد. برای مثال، در عنصر h1، متن یا محتوای تیتر سطح یک بین این دو برچسب کدنویسی می‌شود.

برخی عناصر فاقد محتوا و برچسب پایانی هستند و برچسب‌های خالی نامیده می‌شوند. نمونه‌های رایج آن‌ها عبارت‌اند از:  
-----< br>: برای ایجاد خط جدید.  
-----< img>: برای مشخص کردن تصویری که باید نمایش داده شود.  

هنگام تودرتو کردن عناصر، باید ترتیب بستن برچسب‌ها به‌درستی رعایت شود. برچسب‌های عناصر نباید با یکدیگر همپوشانی داشته باشند؛ بنابراین، ابتدا باید عنصر داخلی بسته شود و سپس عنصر بیرونی.

برای جلوگیری از ابهام خوانش، نام عناصر تک‌حرفی یا مشابه متن عادی درون علامت‌های کوچک‌تر و بزرگ‌تر قرار داده می‌شود؛ مانند عناصر < a> و عناصر < p>.

ویژگی‌های HTML درون برچسب آغازین یک عنصر یا درون برچسب‌های خالی کدنویسی می‌شوند. هر ویژگی معمولاً از سه بخش تشکیل شده است: نام ویژگی، علامت مساوی و مقدار ویژگی.

در HTML5، قرار دادن مقدار ویژگی درون علامت نقل‌قول همیشه اجباری نیست، اما اگر مقدار شامل فاصله باشد، استفاده از نقل‌قول ضروری است. با این حال، توصیه می‌شود برای حفظ خوانایی، یکدستی و کاهش احتمال خطا، تمام مقادیر ویژگی درون علامت نقل‌قول قرار گیرند.

استفاده از هر دو نوع نقل‌قول دوتایی و تکی امکان‌پذیر است، اما توصیه علمی و عملی بر استفاده مستمر از نقل‌قول دوتایی است؛ زیرا باعث یکنواختی کد و پیشگیری از برخی خطاهای نگارشی می‌شود.

یک عنصر می‌تواند دارای یک یا چند ویژگی باشد. برای مثال، عنصر img معمولاً شامل ویژگی src برای مشخص کردن نشانی فایل تصویر و ویژگی alt برای ارائه متن جایگزین در صورت عدم نمایش تصویر است.

ویژگی بولین ویژگی‌ای است که تنها دو حالت روشن یا خاموش را نشان می‌دهد. برای فعال کردن چنین ویژگی‌ای، تنها نام آن کدنویسی می‌شود؛ مانند ویژگی checked که موجب می‌شود کادر انتخاب به‌صورت علامت‌خورده نمایش داده شود. برای غیرفعال بودن آن، ویژگی اصلاً در برچسب نوشته نمی‌شود.

دو ویژگی پرکاربرد برای شناسایی عناصر عبارت‌اند از:  
-----ویژگی id: برای شناسایی یکتای یک عنصر به کار می‌رود و مقدار آن باید در سند HTML منحصر‌به‌فرد باشد.  
-----ویژگی class: برای نشانه‌گذاری یک یا چند عنصر استفاده می‌شود و می‌توان یک مقدار کلاس را به چند عنصر نسبت داد.  

در HTML می‌توان از توضیحات برای شرح عملکرد کد استفاده کرد. توضیحات بین --!> و <-- قرار می‌گیرند و توسط مرورگر نادیده گرفته می‌شوند.

همانند HTML، زبان CSS نیز دارای نحو مشخصی است که هنگام کدنویسی فایل‌های CSS باید رعایت شود.

هر فایل CSS از مجموعه‌ای از قواعد استایل تشکیل شده است. هر قاعده استایل شامل یک **انتخاب‌گر** و سپس **یک جفت آکولاد** است.

درون آکولادها، یک یا چند اعلان قرار می‌گیرد. هر اعلان از یک **ویژگی** و یک **مقدار** تشکیل شده است. نام ویژگی با دونقطه و مقدار آن با نقطه‌ویرگول از هم جدا می‌شوند.

انتخاب‌گر مشخص می‌کند که قاعده استایل بر کدام عناصر HTML اعمال شود. برای مثال، انتخاب‌گر h1 تمام عناصر h1 را هدف قرار می‌دهد و ویژگی color با مقدار navy باعث می‌شود متن این عناصر به رنگ سرمه‌ای نمایش داده شود.

یک قاعده استایل می‌تواند تنها یک اعلان داشته باشد یا شامل چندین اعلان باشد؛ مانند قواعدی که هم‌زمان ویژگی‌هایی مانند font-style و border-bottom را تنظیم می‌کنند.

در CSS می‌توان از توضیحات برای شرح عملکرد کد استفاده کرد. توضیحات بین /* و */ قرار می‌گیرند و توسط مرورگر نادیده گرفته می‌شوند.

انتخاب‌گر در CSS مشخص می‌کند که اعلان‌های یک قاعده استایل بر کدام عنصر یا عناصر HTML اعمال شوند.

سه انتخاب‌گر پایه CSS عبارت‌اند از:  
انتخاب‌گر نوع: نام یک عنصر HTML را هدف قرار می‌دهد؛ مانند body، h1 یا p.  
انتخاب‌گر شناسه: با کاراکتر # آغاز می‌شود و به عنصری اعمال می‌شود که ویژگی id آن با مقدار مشخص‌شده برابر باشد؛ مانند #copyright. این انتخاب‌گر باید به یک عنصر یکتا اشاره کند.  
انتخاب‌گر کلاس: با کاراکتر . آغاز می‌شود و به تمام عناصری اعمال می‌شود که ویژگی class آن‌ها دارای مقدار موردنظر باشد؛ مانند .base_color. این انتخاب‌گر می‌تواند چند عنصر را هدف قرار دهد.  

در قاعده استایل مربوط به عنصر body، می‌توان خانواده قلم را مشخص کرد. اگر قلم اصلی در دسترس نباشد، مرورگر از قلم جایگزین استفاده می‌کند؛ برای مثال، ابتدا Arial و در صورت عدم دسترسی، sans-serif به‌کار می‌رود.

اندازه قلم در عنصر body می‌تواند بر اساس درصدی از اندازه پیش‌فرض مرورگر تنظیم شود. تنظیم آن روی 100% معادل اندازه پیش‌فرض است، اما معمولاً برای کامل‌بودن و کنترل‌پذیری بیشتر کدنویسی می‌شود.

سایر ویژگی‌های عنصر body نیز قابل تنظیم هستند؛ مانند عرض که می‌تواند بر حسب پیکسل مشخص شود، یا بالشتک که می‌تواند بر حسب em تعریف شود. واحد em معمولاً نسبت به اندازه قلم عنصر مرجع محاسبه می‌شود.

قاعده استایل مربوط به h1 می‌تواند اندازه قلم را به‌صورت درصدی از اندازه قلم سند یا عنصر مرجع تنظیم کند؛ برای مثال، 180% باعث بزرگ‌تر شدن متن نسبت به اندازه پایه می‌شود.

انتخاب‌گر شناسه، مانند #copyright، می‌تواند برای قالب‌بندی یک عنصر خاص استفاده شود؛ مانند تنظیم اندازه قلم، راست‌چین کردن متن یا سایر ویژگی‌های ظاهری.

انتخاب‌گر کلاس، مانند .base_color، می‌تواند یک ویژگی مشترک را به چند عنصر مختلف اعمال کند؛ برای مثال، تنظیم رنگ آبی برای تمام عناصری که دارای آن کلاس هستند.

قواعد استایل می‌توانند یکدیگر را بازنویسی کنند. بنابراین، اگر ویژگی‌ای ابتدا برای عنصری عمومی تنظیم شود و سپس برای عنصری خاص‌تر تغییر کند، معمولاً قاعده خاص‌تر یا بعدی اولویت پیدا می‌کند.

این مثال نشان می‌دهد که CSS امکان شناسایی دقیق عناصر و اعمال قالب‌بندی هدفمند را فراهم می‌کند. همچنین، یکی از مزایای اصلی CSS این است که ظاهر و قالب‌بندی صفحه را از ساختار و محتوای HTML جدا می‌سازد.
